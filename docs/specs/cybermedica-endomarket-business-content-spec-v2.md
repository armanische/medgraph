# CyberMedica — Business/Content Corrective v2

Этот документ фиксирует предоставленное Product Owner бизнес-ТЗ. Разработчик применяет готовые тексты и правила без генерации новой маркетинговой логики.

## Каталог

Карточки имеют одинаковую и компактную контентную структуру. Остаются изображение, категория, модель, название, производитель, бейджи «В наличии» и «Рассрочка 0%», максимум два отдельных тега применения с `+N` и CTA «Открыть карточку». Технические характеристики и псевдопреимущества из листинга исключаются. Описание ограничивается двумя строками.

## Product Detail

Hero содержит название, модель/производителя, коммерческие бейджи, текст «До 12 месяцев без удорожания», отдельные теги применения и CTA. При отсутствии страны поле скрывается.

Для импортированных товаров секция называется «Ключевые особенности». В ней остаются только конкретные подтверждённые функции и параметры. Если после очистки список пуст, секция скрывается целиком.

Запрещённые псевдопреимущества:

- «Профессиональное медицинское применение»;
- «Надежное решение для медицинских учреждений»;
- «Используется в клинической практике»;
- применение по отделениям как преимущество.

Каждая область применения выводится отдельным тегом. В hero показываются максимум два тега, остальные представлены счётчиком `+N`.

## Media

Удаляются изображения с watermark EM / EndoMarket, точные и очевидные визуальные дубли. Если одно фото присутствует с watermark и без него, остаётся только чистый вариант. Hero выбирается только из чистых изображений. Коммерческие бейджи не встраиваются в растровые изображения.

## Популярное оборудование

Заголовок: «Популярное медицинское оборудование».

Подзаголовок: «Оборудование для эндоскопии, диагностики и оснащения клиник — в наличии и с рассрочкой 0%.»

Приоритет:

1. SonoScape EG-500
2. SonoScape EC-500T
3. SonoScape EB-500
4. Medinova BR-1231
5. ENDO CLEAN-1000
6. ENDO CLEAN-2000
7. EC-5BD
8. iLivTouch

Резерв: ERBE VIO 3 и BOWA ARC 350.

Карточка допускается только с чистым hero media без fallback. При наличии менее четырёх валидных карточек секция скрывается целиком.

## Сервис

Заголовок: «Сервис и сопровождение оборудования».

Текст: «Гарантийное и постгарантийное обслуживание через сеть профильных сервисных партнеров.»

Блок остаётся внутри существующего блока преимуществ.

## Коммерческие формулировки

Единообразно используются:

- «В наличии»;
- «Рассрочка 0%»;
- «До 12 месяцев без удорожания».

Полные short/full descriptions и списки «Ключевые особенности» для 42 draft Products берутся только из `data/import/source/endomarket-business-content-corrective-v2.json`. Табличная матрица сверки — `data/import/source/endomarket-text-replacements-v2.csv`.
